**NodeX is a refreshed node editor for Autodesk Maya.** It is a fast, zoomable graph board docked
inside Maya that reads and writes your live scene. This patch release makes it sharp and
correctly sized on high-resolution displays, and fixes the fold button.

![NodeX board in Maya](https://raw.githubusercontent.com/tau00/NodeX/v2.0.1/docs/screenshot.png)

## Install in 30 seconds

1. Download **`NodeX-2.0.1.zip`** from *Assets* below.
2. Unpack it anywhere, keeping `install.py` next to the `NodeX` folder.
3. Drag **`install.py`** into a Maya viewport.

Already on 2.0.0? Do the same; it replaces 2.0.0 in place. Scenes, tabs and presets are kept.

## Requirements

- Windows, **Maya 2025 or newer**. Tested on Maya 2026.
- On Maya 2022–2024, use [NodeX 1.0.0](https://github.com/Spaceman582/NodeX/releases/tag/Release)
  instead.

## What's new in 2.0.1

- **Follows Maya's interface scale** (Windows display scaling such as 150% or 200%): the toolbar,
  graph tabs, status row and node search popup now grow with Maya's own UI, sized like the
  Node Editor's. Tab text is no longer cut off at 150%.
- **Sharp icons on high-res displays**: the toolbar icons and the icons in node headers are now
  128 px, so they stay crisp at any zoom and scale. The node search popup uses Maya's larger
  icon art too.
- Fixed: the fold button can unfold a node that shows no rows (for example an unconnected joint).
  Before, such a node looked folded either way and could not be expanded again.
