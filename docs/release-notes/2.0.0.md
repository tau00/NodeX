NodeX 2.0.0 runs on Maya 2025 and newer (PySide6 / Qt 6). It was tested on Maya 2026 with both
Viewport 2.0 backends, Direct3D 11 and OpenGL Core Profile.

## Requirements

- Windows, Maya 2025 or newer. Tested on Maya 2026. A newer Maya shows an "untested version"
  warning when you install.
- Maya 2022–2024: stay on [NodeX 1.0.0](https://github.com/Spaceman582/NodeX/releases/tag/Release).

## Install

Unpack `NodeX-2.0.0.zip` anywhere and drag `install.py` into a Maya viewport. The installer adds
a shelf button and **Windows > NodeX Node Editor**. Full instructions are in `README.txt` inside
the archive.

## Upgrading from 1.0.0

- Installing 2.0.0 replaces 1.0.0 and removes NodeX from Maya 2022–2024 on the same machine.
  The two releases share one install, so only one can be installed per user.
- Scenes saved with 1.0.0 (the `nodexBoard` network node) open unchanged, and presets in
  `Documents/maya/nodex_presets` are kept.
- If you install a newer Maya later, drag `install.py` into it once. The module is only enabled
  for the Maya versions it was installed from.

## Changes

- Ported from PySide2 / Qt 5.15 to PySide6 / Qt 6.
- The dot grid and the far-zoom node outlines now use precompiled Qt 6 shaders, so they draw on
  both Direct3D 11 and OpenGL.
- Every QML signal handler was updated, so Qt 6 no longer prints deprecation warnings in the
  Script Editor.
- The inbetween socket dialog no longer stays alive, hidden, after each insert.
