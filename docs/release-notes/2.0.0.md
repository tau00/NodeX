**NodeX is a refreshed node editor for Autodesk Maya.** It is a fast, zoomable graph board docked
inside Maya that reads and writes your live scene. Its colours come from your own Maya
preferences. This release brings it to **Maya 2025 and newer**.

![NodeX board in Maya](https://raw.githubusercontent.com/tau00/NodeX/v2.0.0/docs/screenshot.png)

## Install in 30 seconds

1. Download **`NodeX-2.0.0.zip`** from *Assets* below.
2. Unpack it anywhere, keeping `install.py` next to the `NodeX` folder.
3. Drag **`install.py`** into a Maya viewport.

You get a **NodeX** shelf button and **Windows > NodeX Node Editor**. Press **Help > Keys**
inside the editor for the shortcuts. If Maya asks at the next start whether to allow the
module's `userSetup.py`, allow it, or the Windows menu item won't appear.

Remove it from Maya's Script Editor (Python) with
`import nodex.startup; print(nodex.startup.uninstall())`, then restart Maya.

## Requirements

- Windows, **Maya 2025 or newer**. Tested on Maya 2026 with both viewport engines, Direct3D 11
  and OpenGL.
- A Maya newer than 2026 shows an "untested version" warning at install. Please report anything
  that breaks.
- On Maya 2022–2024, use [NodeX 1.0.0](https://github.com/Spaceman582/NodeX/releases/tag/Release)
  instead.

## What you get

- A pannable, zoomable board with level-of-detail drawing, so large rigs stay smooth.
- Drag-to-connect wiring, link-drag search, bulk connect by name, reroute, swap and transfer.
- Inbetween and unit-conversion nodes handled as part of the wire.
- Value fields with drag-slide, multi-field sweep and typed entry, each one undo step.
- Copy, paste and duplicate of node fragments, plus JSON presets.
- Graph tabs, node positions and frames saved inside the scene.
- Auto layout: rearrange, align, grid and straighten.

## What's new in 2.0.0

- **Runs on Maya 2025+**: ported from PySide2 / Qt 5 to PySide6 / Qt 6.
- The dot grid and the far-zoom node outlines use precompiled Qt 6 shaders, so they draw on both
  Direct3D 11 and OpenGL.
- No Qt deprecation warnings in the Script Editor.
- Fixed: the inbetween socket dialog no longer stays alive, hidden, after each insert.

## Upgrading from 1.0.0

- Installing 2.0.0 replaces 1.0.0 and removes NodeX from Maya 2022–2024 on the same machine.
  Only one of the two can be installed per user.
- Scenes saved with 1.0.0 open unchanged, and your presets in `Documents/maya/nodex_presets`
  are kept.
- If you install a newer Maya later, drag `install.py` into it once.
