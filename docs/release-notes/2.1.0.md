**NodeX is a refreshed node editor for Autodesk Maya.** It is a fast, zoomable graph board docked
inside Maya that reads and writes your live scene. This release makes the board follow nodes you
create anywhere else in Maya, with a switch to turn that off, and fixes a crash after reloading a
plug-in.

![NodeX board in Maya](https://raw.githubusercontent.com/tau00/NodeX/v2.1.0/docs/screenshot.png)

## Install in 30 seconds

1. Download **`NodeX-2.1.0.zip`** from *Assets* below.
2. Unpack it anywhere, keeping `install.py` next to the `NodeX` folder.
3. Drag **`install.py`** into a Maya viewport.

Already on 2.0.x? Do the same; it replaces the old version in place. Scenes, tabs and presets are
kept.

## Requirements

- Windows, **Maya 2025 or newer**. Tested on Maya 2026.
- On Maya 2022–2024, use [NodeX 1.0.0](https://github.com/Spaceman582/NodeX/releases/tag/Release)
  instead.

## What's new in 2.1.0

- **New nodes join the open tab**: nodes you create outside NodeX (Script Editor, Hypershade,
  Maya's Create menus) now appear on the active tab while *Sync with scene* is on. In 2.0.x this
  never happened. Nodes from file open, import and reference are still left out.
- **Options > Add new nodes to tab** switches this off, so a hand-picked board stays as it is
  while you script a rig. Deleting and renaming still sync. NodeX's own Create, paste, presets and
  inbetween always place their nodes. The choice is saved on your machine and applies to every
  scene.
- Fixed: renaming a node outside NodeX now refreshes it on the board straight away.
- Fixed: after unloading and reloading a plug-in, showing that plug-in's nodes no longer fails with
  "Object does not exist" or crashes Maya.
- If a scene callback ever fails, NodeX now prints a warning in the Script Editor instead of
  failing silently.
